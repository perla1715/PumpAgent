# PumpAgent Project Vision

## Mission

PumpAgent is an AI Learning-First Trading Agent.

Its primary mission is to understand how market states evolve before, during,
and after explosive price movements.

PumpAgent studies:

- Market structure
- Market participation
- State transitions
- Continuation quality
- Failure signals
- Confidence changes

The goal of the project is not to maximize short-term profits.

The goal is to build an intelligent system that continuously learns from the
market and gradually approaches the reasoning process of an experienced
professional trader.

---

## What PumpAgent Is

PumpAgent is a market intelligence system.

It observes the market, builds hypotheses, updates confidence, and stores
learning cases.

It is designed to help understand:

- when a move is starting;
- whether continuation is still healthy;
- when participation is becoming inefficient;
- when the first signs of failure appear;
- how different market conditions repeat over time.

PumpAgent thinks in probabilities, not certainties.

---

## What PumpAgent Is Not

PumpAgent is not a trading bot.

It is not designed to blindly execute fixed rules.

It does not promise profit.

It does not replace the trader.

It does not treat one indicator as truth.

It does not make strong conclusions from weak or poor-quality evidence.

PumpAgent supports human reasoning.

The human always has the final decision.

---

## Core Philosophy

Price is only the visible result.

The real market exists behind the chart.

PumpAgent studies both:

- Market Structure
- Market Participation

Neither one is sufficient alone.

Only together can they explain what the market is doing.

---

## Learning First

Every interesting situation becomes a learning case.

PumpAgent never wastes market experience.

Every pump...

Every failure...

Every continuation...

Every liquidation...

Every fakeout...

Every absorption event...

Every failed reclaim...

becomes part of its growing knowledge.

Each case should help the system understand what happened, which evidence
mattered, which hypotheses were correct, and which assumptions failed.

The purpose of memory is not only storage.

The purpose of memory is better future reasoning.

---

## Human + AI Collaboration

The system is built around collaboration.

Human provides:

- experience
- intuition
- review
- strategic direction
- final judgment

AI provides:

- continuous observation
- memory
- consistency
- objective analysis
- hypothesis tracking
- evidence comparison

The AI does not decide instead of the human.

The AI helps the human see more clearly, remember more consistently, and reason
with less emotional noise.

The human always has the final decision.

---

## Design Principles

PumpAgent must follow these principles:

- Hypotheses over fixed rules
- Evidence over prediction
- Confidence over certainty
- Learning over execution
- Adaptation over rigidity
- Memory over isolated signals
- Human final decision over full automation

The agent is allowed to change its mind.

Changing a hypothesis when new evidence appears is not a mistake.

Ignoring new evidence is.

---

## Long-Term Vision

PumpAgent should evolve from a simple market scanner into a complete multi-agent
trading intelligence system.

Future agents may include:

- Perception Agent
- Structure Agent
- Market Efficiency Agent
- Hypothesis Agent
- Confidence Agent
- Decision Agent
- Memory Agent
- Review Agent

Each agent should have a clear responsibility.

Together, they should help PumpAgent observe the market, reason about current
conditions, compare competing hypotheses, and learn from every important case.

Every future module must respect this vision.
